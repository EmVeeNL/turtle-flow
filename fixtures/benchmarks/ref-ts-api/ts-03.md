# Validate an item request

Export `validateItem(value: unknown): { valid: boolean; errors: string[] }` from `src/api.ts`. A valid item is an object with a non-empty string `name` of at most 80 characters and an optional array of string `tags`. Return errors in this order: `name must be a non-empty string of at most 80 characters`, then `tags must contain only strings` when the corresponding field is invalid. Return no errors for valid input.
